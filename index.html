기능 관련

  1. ai 활용해서 앱/웹 서비스 빠르게 만드는 tip
  2. 결제 기능 붙이기(카드결제, 토스페이먼츠 등등..)
  3. 소셜 로그인 기능 붙이기
  4. 외부 서비스 연동 기능붙이기(e.g., 웹서비스 안에서 일정을 입력하면 -> 구글 캘린더에 추가할 수 있는 기능)
  5. QA 엔지니어 agent 만들기

비즈니스 관련

  1. 서비스를 런칭한 후에 개발자 없이 혼자서 유지보수를 어떻게 해야하는가?(개발 오류 대응을 어떻게 해야할지)
  2. 서비스 고도화를 하게 될 경우 1인 창업가로서 고려해야 할 것들

실제 창업가분들께 조언받고 싶은 것

  1. 이 부트캠프의 수료생분들 중에서 실제로 출시한 it 서비스를 지금까지 어떤식으로 운영해오고 계신지?...
  2. 여긴 개발자가 아닌 창업가 과정이라 실제 개발할 땐 ai의 힘을 좀 빌릴 것 같은데, 그 과정에서 개발 지식을 얼마나 습득해야 직접 내 서비스를 핸들링할 수 있을지?
  3. 그리고 요즘 Ai 기술이 좋아서 창업하기 좋은 시대라고 하는데 실제로 창업해보니 어떠실지 궁금합니다.
